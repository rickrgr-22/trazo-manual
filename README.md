# Manual de operación de Trazo

Este repositorio publica únicamente la guía de uso de Trazo para Rodríguez Arquitectos; no contiene el código de la aplicación, su base de datos ni credenciales.

**Leer el manual:** https://rickrgr-22.github.io/trazo-manual/

Las capturas usan datos ficticios. La guía incluye una matriz honesta de las 20 áreas de la propuesta integral, con las funciones parciales y pendientes identificadas.
